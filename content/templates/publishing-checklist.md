# Publishing checklist

- **Piece (Required):** [Final title]
- **Format / channel (Required):** [Article / long-form / short-form; destination]
- **Status (Required):** Packaging
- **Owner:** [Name]
- **Target publication date:** [YYYY-MM-DD]
- **Next action (Required):** [Concrete step]

## Editorial and factual review

- [ ] Thesis, audience, original angle, and payoff are clear.
- [ ] Argument or story flows; examples earn their place.
- [ ] Counterargument and material uncertainty are represented fairly.
- [ ] Names, dates, numbers, quotes, claims, and attributions checked against sources.
- [ ] Claims match what the evidence supports; causal language is justified or qualified.
- [ ] Rights, privacy, permissions, and sensitive details reviewed.
- [ ] Copy edit and format-specific read-through complete.

## Title, metadata, and assets

- **Final title (Required):** [Accurate, clear title]
- **Excerpt / description (Required):** [Concise and representative]
- **SEO title:** [If distinct]
- **SEO description:** [Plain-language page summary]
- **Canonical URL / slug:** [Planned URL]
- **Image orientation (Required if image used):** [Landscape / portrait / square]
- **Aspect ratio (Required if image used):** [Ratio]
- **Image asset path (Required if image used):** [Repository-relative path]
- **Alt text (Required if image used):** [Purposeful description]
- **Image credit / rights:** [Credit, license, permissions]
- **Open Graph / social preview image:** [Path, orientation, ratio, check status]
- **Captions / transcript (video):** [Path or status]
- **Source credits:** [In-page references, end cards, or description]

- [ ] Image crop and thumbnail remain clear at mobile size.
- [ ] All asset paths resolve in the final location; no temporary links remain.
- [ ] Filename, case, spaces, and relative paths match the static site.
- [ ] Social title, description, canonical URL, and image match the finished piece.

## Site placement and usability

- **Destination (Required):** [Notes page / Selected Work page / other]
- **Page path:** [e.g. `notes/slug.html` or `scripts/slug.html`]
- **Listing update:** [e.g. `notes.html` or `work.html` entry]
- **Internal links:** [Relevant pages and link text]
- **External links:** [Checked destinations; new-tab behavior where used]

- [ ] Heading hierarchy and page title are clear.
- [ ] Main content, images, captions, and links work on mobile widths.
- [ ] No unintended horizontal overflow; text and controls remain usable.
- [ ] Images have useful alt text or are marked decorative as appropriate.
- [ ] Keyboard focus and navigation are usable; link text makes sense out of context.
- [ ] Internal links, external links, and image paths checked.
- [ ] Listing card, category, title, and description accurately match the page.
- [ ] Page remains understandable if an external embed or image is unavailable.

- **Final review by / date:** [Name / YYYY-MM-DD]
- **Publication status (Required):** [Ready / Scheduled / Published / Parked]
- **Published URL:** [URL when live]
- **Publication date:** [YYYY-MM-DD]

Do not mark `Published` until the live page and its listing have been checked. Site deployment is a separate release step.
