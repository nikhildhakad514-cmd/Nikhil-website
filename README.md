# Nikhil Dhakad — Personal portfolio

A lightweight, static personal site for selected work, writing, and ongoing interests. Built with HTML, CSS, and vanilla JavaScript.

## Art direction

**Editorial field notes:** near-black canvas, warm white typography, restrained red accents, expressive serif display type, asymmetrical work layouts, and quiet navigation. The site is intended to feel like a personal notebook and an exhibition of real work, not a service template.

## Pages

- \`index.html\` — point of view, selected work, and latest published writing
- \`work.html\` — script projects and visual concepts with honest context
- \`notes.html\` — published writing and questions in progress
- \`about.html\` — interests and working perspective
- \`contact.html\` — direct contact links
- \`blog.html\` — legacy redirect to Notes

## Stack

- HTML5
- CSS3, responsive layout, reduced-motion support
- Vanilla JavaScript for mobile navigation only
- Google Fonts (DM Sans and DM Serif Display)

No framework, build step, external animation library, invented metrics, or fabricated testimonials.

## Local preview

Open \`index.html\` directly in a browser or serve the folder with any static HTTP server. The image paths in \`assets/images/thumbnails/\` refer to existing project assets.

## Deployment

The site is configured for static hosting on Vercel. Push the reviewed changes to the production branch only when ready to publish.
